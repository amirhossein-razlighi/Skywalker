# Credits: Vehicle Yard

- **Coupe and wheels** (`models/*.glb`): an original design built procedurally with
  `models/make_coupe.py` (Blender 3.5+, `Blender -b --python models/make_coupe.py -- models`).
  Released under CC0-1.0 with this project.
- **Asphalt textures** (`textures/asphalt_*`): the project's own, shared with `examples/toy_kart_rally`.
- **Engine sound** (`audio/engine_loop.wav`): generated by the engine's synthesizer (`engine_loop` preset)
  when `vehicle_create` set the car up.

Everything else (cones, barriers, ramps, poles, markings) is built from engine primitives.
