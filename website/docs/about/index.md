# About Skywalker

Skywalker is a game engine built from the ground up for AI agents and the people who work with them. It is a C++20
engine with a native SwiftUI editor for macOS and a Metal renderer (with a CPU renderer for headless use), a
deterministic simulation, the Wander behavior language, an MCP tool surface shared by every client, and a multi-agent
studio that plays, triages, fixes and verifies games.

Skywalker is developed by **AmirHossein (Amir) Razlighi**.
